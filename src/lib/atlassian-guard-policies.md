Keeping sensitive data safe inside collaboration tools like Jira or Confluence is one of the biggest challenges for any team. A single slip when uploading a file or pasting a key can compromise the security of the entire organization.

With **Atlassian Guard**, you can proactively prevent these risks by creating **custom policies that trigger on a specific condition**, instantly executing the corresponding action to protect your environment.

## Full Control over Sensitive Data

Thanks to its extensive list of supported sensitive data types (such as credentials, financial data or personal information), Atlassian Guard automatically detects any unwanted exposure and acts according to the rules you have previously defined: from sending alerts to restricting access to the content.
